# 风电示廓系统
## 项目简介
本项目是一个基于STM32F103C8T6的工业级激光二极管驱动与控制系统，支持三路独立激光二极管的低纹波控制。系统集成了RS485等多模式通信、实时温度监测、PWM调光和远程固件升级（IAP）等功能，同时具备恶劣工况下的防雷击、防浪涌能力，适用于需要多通道激光控制的工业应用场景。当前用于风电系统示廓。

## 核心特性
-**多通道激光驱动**：通过SPI接口控制10-bit DAC（MS5314），配合LM3409恒流驱动芯片，实现三路激光二极管的独立电流控制，功率级数0-4095可调；  
-**实时温度监测**：采用ADC+DMA方式采集三路NTC热敏电阻，集成滑动平均滤波算法，温度测量稳定；  
-**FreeRTOS任务调度**：划分RS485命令处理、温度采集、LED指示灯等独立任务，通过信号量和消息队列实现任务间同步与通信；  
-**RS485通信协议**：基于USART+空闲中断的可变长数据帧解析，支持开关控制、功率设定、状态查询等命令；  
-**IAP远程固件升级**：支持通过RS485接口进行固件升级，具备CRC32校验、超时保护和看门狗复位机制，基于状态机完成固件升级，最大限度保证系统健壮性，不会因为异常而导致程序卡死，进而需要手动复位等；  
-**配置参数掉电保存**：利用PVD中断在系统掉电时将关键参数写入内部Flash，重新上电后读取参数并完成初始化，减少Flash擦写次数。

### 编译与烧录
#### Bootloader (起始地址: 0x08000000)
1. 编译Bootloader工程，生成 .bin 文件
2. 通过ST-Link烧录Bootloader
#### APP (起始地址: 0x08004000)
1. 修改APP工程的IROM1起始地址为 0x08004000
2. 建议在main函数开头添加: SCB->VTOR = 0x08004000;
3. 编译生成 .bin 文件
4. 通过ST-Link烧录APP，或通过上位机IAP升级

## APP程序
模块化分层，架构清晰，多层解耦，以便复用、移植、扩展和维护，具有多任务实时调度、外设驱动抽象和上位机控制能力，实时性强、通信可靠、系统健壮。
### 驱动层（驱动代码均可复用）
1、片内ADC+DMA的三路NTC温度采集，并对温度数据滑动平均滤波以抑制噪声，提高测量稳定性；
2、片内Flash读写与擦除；
3、RS485收发，包括帧解析和校验；
4、MS5314 DAC芯片驱动（SPI通信）,为LM3409 LED驱动芯片提供模拟电压以实现模拟调光；UCC27511栅极驱动芯片可进一步实现PWM调光。
### 硬件抽象层HAL
1、封装了激光二极管开关控制和功率级数设定、上位机通信（接收与回传）、配置参数从Flash加载或保存至Flash；
2、将所有硬件和配置参数的初始化封装；
### 应用层
1、基于FreeRTOS多任务实时调度，低优先级默认任务执行LED灯闪烁以便调试直观观察，中优先级温度采集任务每秒采集一次三路激光二极管温度，高优先级上位机数据帧处理任务解析并执行上位机指令；
2、不定长数据帧处理：使用UART空闲中断快速处理上位机下发的不定长数据帧并完成校验，将数据通过消息队列传递至阻塞的上位机数据帧处理任务；
3、通信机制：FreeRTOS软件定时器释放信号量以唤醒阻塞的温度采集任务；
4、配置数据保存：使用PVD掉电中断，在系统掉电时保存关键配置数据，上电/复位时读取配置数据并完成初始化，有效减少Flash擦写；
5、激光控制：三路激光可由上位机单独开关和设置功率级数（4095级精确控制），可由霍尔传感器触发（在风电示廓系统中，霍尔传感器用于检测叶片，叶片经过时亮起激光二极管以示廓），也可由上位机控制常亮。得益于硬件设计，激光二极管驱动电流纹波降低至驱动电流值的5%左右；
6、独立看门狗：通过FreeRTOS软件定时器定时刷新看门狗，不干扰其他任务，并防止程序卡死。

## BootLoader
1、基于状态机编写升级流程，并使用独立看门狗避免程序卡死，始终确保可恢复性，而不必在异常出现时需要手动复位或重新擦除Flash，对于风电等恶劣环境下的维护非常友好；
2、正常情况下，上电后BootLoader会直接跳转到APP程序（有2s时间供确认是否直接跳转），APP程序也可发起固件升级，复位回到BootLoader进行升级，所有异常都可导致最终进入到“等待固件升级”阶段，而不是复位后循环卡死；
3、基于简单状态机逐字节接收和处理数据帧，以此处理不定长数据帧，并尽可能减小程序大小。

## 上位机
由AI生成的基于PySide6的上位机，能够显示激光二极管温度、出光功率级数和开关状态，以及控制模式、设备信息等，还可根据预定的数据帧格式完成光源控制、功率级数和控制模式设定，以及灵活可控的固件升级
