风电示廓系统
项目简介
本项目是一个基于STM32F103C8T6的工业级激光二极管驱动与控制系统，支持三路独立激光二极管的低纹波控制。系统集成了RS485等多模式通信、实时温度监测、PWM调光和远程固件升级（IAP）等功能，适用于需要多通道激光控制的工业应用场景。当前用于风电系统示廓。
核心特性
多通道激光驱动：通过SPI接口控制10-bit DAC（MS5314），配合LM3409恒流驱动芯片，实现三路激光二极管的独立电流控制，功率级数0-4095可调
实时温度监测：采用ADC+DMA方式采集三路NTC热敏电阻，集成滑动平均滤波算法，温度测量稳定
FreeRTOS任务调度：划分RS485命令处理、温度采集、LED指示灯等独立任务，通过信号量和消息队列实现任务间同步与通信
RS485通信协议：基于USART+空闲中断的可变长数据帧解析，支持开关控制、功率设定、状态查询等命令
IAP远程固件升级：支持通过RS485接口进行固件升级，具备CRC32校验、超时保护和看门狗复位机制，基于状态机完成固件升级，最大限度保证系统健壮性，不会因为异常而导致程序卡死，进而需要手动复位等
配置参数掉电保存：利用PVD中断在系统掉电时将关键参数写入内部Flash，重新上电后读取参数并完成初始化，减少Flash擦写次数
